  4. **步驟 4**：SWOT 因果推論四象限四部曲綜合矩陣（SO積極開拓、WO借力補強、ST防禦轉化、WT避險聚焦）

  6. **步驟 6**：STP 品牌定位宣言與 4P 行銷組合（原肉厚切乾 NT$160、薄切洋芋片 NT$140、日系純棉背心 NT$220、任選三件 NT$399、常溫超取運費 60 元、#毛孩卡滋挑戰 社群傳播）

## GitHub Pages 快速部署 3 步驟

1. **建立儲存庫 (New Repository)**：
   - 登入 [GitHub](https://github.com/login)
   - 點擊右上角「+」➔「New repository」，取名為 `creative-midterm`（或自訂主題）
   - 勾選 **Public**，點擊「Create repository」
2. **上傳本專案檔案**：
   - 點擊「Add file」➔「Upload files」
   - 將本資料夾內的 `index.html` 直接拖進視窗，點擊綠色「Commit changes」
3. **開啟 GitHub Pages 雲端發布**：
   - 進入儲存庫「Settings」➔ 左側「Pages」
   - 在「Build and deployment」下的 Branch 選為 `main`，資料夾為 `/(root)`，按「Save」
   - 等待約 1 分鐘，即可獲得正式公開網址：`https://<你的GitHub帳號>.github.io/<專案名稱>/`！
