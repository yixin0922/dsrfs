Brand Philosophy

品牌故事與品質堅持

我們相信，毛孩是家人，值得與我們同等水準的純淨安心。

從自製一份給家人的安心下午茶開始

走進量販超市，架上琳瑯滿目的寵物零食，背後標籤卻常見看不懂的化學甘油、山梨酸鉀與重組肉粉。許多毛孩因為過敏而抓癢紅腫，飼主更在不透明的成分前猶豫卻步。

《樂肉選品 (LeRou Pet Goods)》創辦緣起，正是為了打破「拼裝低價」與「高昂冷鏈鮮食」的兩難天秤。我們採用在地合格產銷履歷生鮮雞肉與黃金地瓜，以小批量 65°C~70°C 低溫風乾慢烘，將多餘水分抽離，僅留下天然濃醇肉香與酥脆口感。

🌾 在地履歷食材

選用台灣國產生鮮清胸肉與台農黃金地瓜，減少碳足跡與食物里程。

⏱️ 72小時慢工烘烤

不搶快、高溫不焦化，以時間凝聚原肉最真誠的營養與甘美。

⚠️ 痛點 1：市售過度添加與成分黑箱

市售大包裝肉乾多含大量化學甘油、防腐劑與澱粉肉粉混充，飼主無法辨認真實肉質纖維，缺乏最基本的食品安全信任。

📦 痛點 2：鮮食冷鏈運費阻礙下單

低溫冷凍宅配單筆運費動輒 160~220 元，新手飼主首購意願極低；反觀「常溫原肉烘乾」超商取貨僅需 60 元，大幅降低下單阻力且無保存耗損風險。

☕ 痛點 3：欠缺生活美學儀式感

傳統寵物零食包裝俗豔且質地死硬。缺乏能讓現代飼主在居家下午茶時光，與毛孩一同分享香脆「卡滋脆片」的極簡質感體驗。

Deployment Roadmap

GitHub Pages 免費雲端靜態發布操作指引

依據授課教師邱俊維博士期中規範，本網頁為單一 index.html 檔案架構，只需三步即可在全世界公開瀏覽！

01

登入 GitHub 並開立儲存庫 (Repo)

前往 GitHub.com 登入，點擊右上角「+」➔「New repository」。輸入儲存庫名稱（如 creative-midterm），務必勾選 Public（公開） 與 Add a README file，點擊綠色按鈕建立。

02

上傳 index.html 檔案

進入剛建立好的儲存庫頁面，點選「Add file」➔「Upload files」，將您電腦中的 index.html 拖曳到上傳視窗中，點擊底部的綠色「Commit changes」按鈕確認存檔。

03

一鍵啟用 GitHub Pages

點選儲存庫上方導覽列的「Settings」➔ 左側「Pages」➔ 在 Build and deployment 底下的 Branch 由 None 改選為 main，資料夾維持 /(root)，按「Save」。等待約 1 分鐘即可取得您的公開成果網址！
